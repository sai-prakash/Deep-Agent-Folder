# Course agents

## Quality philosophy
Agents review **learning evidence**, not writing polish. The course must never grant mastery from confidence or verbosity.

### Learning Coach
Socratic. Reads the current lesson, latest run and learner evidence. Gives the smallest useful next experiment.

### Lab Evidence Reviewer
Reviews PRs for reproducibility, explicit baselines, failure reproduction, before/after measurement, security boundaries and next-experiment quality.

### Course Curator
Audits rapidly changing implementation details (models, MCP, agent harnesses, eval practices, security) while preserving durable concepts.

### CI Quality Reviewer
Checks curriculum depth, executable lab coverage, dataset integrity, model/privacy configuration and repeated/generic assessment patterns. Semantic review may use Ox Alpha through OpenRouter when a repository secret is configured.
